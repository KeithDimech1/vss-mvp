# The Item Details page presents an in-depth view of all the data associated with a submitted document.

 

The** Item Details** page consists of the document image and several tabs that provide additional information about the item.

 

- [The Item details page](https://help.dext.com/en/s/article/the-item-details-page#item-details)

- [The Messages, Notes and History tabs](https://help.dext.com/en/s/article/the-item-details-page#message-notes-history)

 

 

# The Item Details Page

 

Access the Item Details page for a specific item by:

 

1. Going to the Costs or Sales Inboxes.
2. Clicking on the relevant item.

 

# The Details tab

 

The Details tab displays all the extracted information from the document, including the Document owner, Type, Date, Supplier, Document reference, Due date, Category etc.

 

Edit the values by clicking into the relevant field. Any changes you make will be saved automatically and immediately.

# The Messages, Notes and History tabs

 

Next to the Item details tab are the Messages, Notes and History tabs.

 

# The Messages tab

 

The Messages tab allows you to see the messages between you and the client relating to this item. Please note, this tab is only present for Optimize account owners or those who have purchased the Targeted Communication add-on.

The notes tab allows you to add any extra information about a particular item, or provide extra detail for your colleagues.

# The History tab

 

The history tab allows you to see a [detailed history](https://help.dext.com/en/s/article/viewing-an-items-history/) of who submitted this document and all the changes that have been made to its associated data in Dext.
