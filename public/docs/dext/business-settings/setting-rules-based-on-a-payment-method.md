**Payment Method Rules allows you to apply your specified details to all submitted documents that were paid for using that payment method.**

 

This article is relevant to the enhanced Dext experience. You can access the article for the legacy Dext experience [here](https://help.dext.com/en/s/article/how-to-set-rules-based-on-payment-method).

 

This can be used to code data automatically as soon as it’s received.

 

 

**Important**: To be able to access and edit payment methods you must be assigned the Admin [role](https://help.dext.com/en/s/article/roles-permissions). To gain this access contact your account administrator.

 

 

# Setting Up a Payment Method Rule

 

To set up a payment method rule:

 

- Go to **Business settings**, **Lists**, then **Payment Methods**.

 

This page will show you your existing payment methods, and from here you can also create new payment methods if needed.

 

- If you need to set up a new payment method, go to **Add payment method**, and enter the name of the method and its reference number, for example the last 4 digits of that card. When ready click **Add**.

- The method will then be listed with your other payment methods, and you can then:

 

- Set Auto-publish to Yes or No.

- Select the Publishing destination for items paid for by this payment method.

- Link a Bank Account from your integrated software to a payment method.

- Optional, click the Set** user defaults** button. Here you can set a default payment method for the users in your account. When they upload a document, the default payment method will be applied.

 

[](https://dext.intercom-attachments.eu/i/o/weauzzxo/65608779/8cbff111884348a3ece147698477/47907_c64125cccae06e63c075bdb1c43068ef.jpg?expires=1765161000&signature=78bffa0abe691a23c1a466931f3533a633e88eb09a29ff7533ac8113c4402e0d&req=1tBpxVD9qz5k2hL085ZhofMYyeD8b9ObShNhWir38XMuZMHBDwad9FVZoGEC%0AfMLVvX9cK9a2pRZc%0A) 

In the **APPLICATION RULE** column you can also set a application rule to add exceptions to your User Defaults:

 

- **No default set**

- **Use default if blank**: To apply your payment method to new documents when no other payment is detected.

- **Always use default**: To always apply your payment method, even if we detect a different payment method on the image.

 

Payment Method Rules take effect before Supplier Rules, and take priority over Supplier Rules if a rule has been set for the same field in both features.
