# User Rules can be used to automatically apply a Payment Method or Project to any Costs transactions uploaded by a specific user.

 

- [Setting a Payment Method Rule](#payment-method-rule)

- [Setting a Project Rule](#project-rule)

 

 

**Note:** User Rules will always overwrite [Supplier Rules](https://help.dext.com/en/s/article/How-to-use-Supplier-and-Customer-Rules) if an item is submitted with User Rules and Supplier Rules for the same field.

 

 

# Setting a Payment Method Rule

 

Setting a payment method rule will apply the same payment method to each item uploaded by a specific user.

 

To set a payment method rule:

 

- Navigate **Business settings** then **Lists **and select **Payment Methods.**

- Ensure you have the necessary payment methods already set up, if not see how to do this [here](https://help.dext.com/en/s/article/how-to-link-a-payment-method-to-a-bank-account).

- Click** Set user defaults.**

- Select the default payment method from the drop down list next to the relevant user.

- Next, select the Application Rule to determine whether this should take effect for every item (**Always use default**), just for items with no Payment Method detected (**Use default if blank**), or leave it as **No default set**.

# Setting a Project Rule

 

To set up a project rule:

 

- Navigate to **Business settings**, then **Lists** and select **Projects**.

- Click **Set user defaults**.

- Then assign the default project for each user using the drop down list.

 

Now, whenever a user uploads an item, the selected project will be automatically assigned to that transaction.
