# Dext integrates with the Australian Business Register ABN Lookup tool, to cross check a contact’s ABN. Dext will automatically highlight all missing or invalid ABN numbers in your accounting software for a client, and identify any transactions with inconsistent tax rates, saving hours of checking time for you and your team.

 

If you use Xero, you can also push a missing ABN number identified in the ABR straight to Xero using Dext.

 

 

**Note**: The ABN validation is available for users with the Data Health & Insights add on. If you&#x27;re an existing Precision user, you&#x27;ll also have access to this.

 

 

To run the ABN validation, go to **Data Health **and then** ABN validation** under a **Data Health & Insights client**.
