Some items you upload to Dext may be rejected or accepted without data being extracted. This happens for a few specific reasons.

 

This article explains the most common causes and what each message means.

# When an item is rejected

If your file is rejected, it’s not stored in our system and will not appear in your **Submission History**. These files are blocked before they reach our servers, so no data is captured or saved.

 

## "This item already exists in your account**.**”

This means the **same file** has already been submitted. The system checks for identical uploads across all submission methods - including email, mobile app, and direct upload.

 

For example, if you email a PDF and later upload the same file manually, the second upload will be rejected.

**Note**: If you upload a **different image/file** of the same receipt or invoice, it may not be rejected, but it could be marked as a **duplicate item**. Learn more about how Dext handles duplicates [here](https://help.dext.com/en/articles/216124-how-does-dext-handle-duplicate-documents).

## **"File type is not supported"**

This means the submitted file&#x27;s format is not supported by our system. Check the supported file types [here](https://help.dext.com/en/articles/416681-what-file-types-can-i-upload-to-dext). 

 

# When no data is extracted

Sometimes, your file is accepted and appears in your inbox, but Dext is unable to extract any useful data. In such cases, we&#x27;ll leave a warning message on the **Item Details** page.

This usually happens for one of the following reasons:

 

## Multiple transactions on the same upload

The image includes more than one receipt or transaction. This can confuse the system and result in incomplete data.

 

The file is added to your inbox, but you’ll need to review and separate the transactions manually using the **Split tool**.

 

## Poor image quality

The system couldn&#x27;t read the content due to image issues. Common problems include:

- Blurry or low-resolution photos

- Torn, crumpled, or damaged documents

- Text that’s too small or faint to scan

The file is still saved to your account, but without extracted data. We recommend re-uploading a clearer version.

 

## That’s not an invoice

If the file doesn’t resemble a receipt, bill, or invoice - for example, if it’s a photo of a personal item or unrelated document - no data will be extracted.

 

The file will still appear in your inbox, but won’t be processed further.

 

# Where do rejected documents go, and how can I view them?

Rejected uploads aren’t stored in your Dext account because they aren’t processed by the extraction engine, so no item is created. 

 

On the web app, you’ll see the rejection message and reason in the **Add documents** panel at the moment of upload, but the file won’t be available afterward.

 

[](https://downloads.intercomcdn.eu/i/o/weauzzxo/75492092/2ffdde9dd76bad701aba2ecff9e6/image.png?expires=1765161000&signature=f4c5b4a89f20955c68599711c47e6358d221a6e7d864a88020d6f1aac4913e8f&req=19BrzFr6pTVk2hL085ZhoUBDt75ZB4%2FHs3WYsBsaeYueV3PEAnn97zq6NP7C%0A3RFzARX9%2FkKW7Usl%0A) 

On the mobile app, you’ll see a “You have X rejected uploads” banner in your inbox. Selecting **Review items** opens the Rejected uploads screen with two tabs:

- **Retry available** – files rejected due to temporary issues (like connection problems). You can preview the file and retry the upload.

- **Invalid files** – files rejected due to permanent issues (like duplicates or unsupported formats). You can preview the file, but deleting it is the only option.

In both tabs, tapping a file opens a preview before you choose your next step.

 

# How to prevent upload issues

To reduce the chance of rejections or missing data:

- Upload only clear images of financial documents (receipts, invoices, or bills)

- Avoid submitting the same file more than once

- Use the **[Split](https://help.dext.com/en/articles/416731-splitting-items)** tool for files with multiple transactions

If your item continues to be rejected or fails to extract data, [contact our support team](https://help.dext.com/en/articles/105691-how-to-contact-our-dext-support-team) for further assistance.
