**Easily add documents to Dext via Whatsapp **

 

 

# Connecting to your Whatsapp Account

 

To connect your Whatsapp account to your Dext account:

- Go to Teams or Users and click on the user you wish to set up the connection for

- Scroll down to Whatsapp and click **Activate **

- Enter the user’s phone number and click **Confirm**

# Adding Documents via Whatsapp Web App

 

To add a document to Dext via Whatsapp:

- With the Whatsapp web app open, go to the chat with Dext and simply drag and drop the relevant file into the chat window

- Alternatively you can click the **+** icon at the bottom of the chat window then find and select the relevant file

- The item will then appear in the Costs  Inbox

 

# Adding Documents via Whatsapp Mobile App

To share a file from Whatsapp to Dext:

- In Whatsapp go to the chat with Dext and click the **+** button at the bottom of the chat

- Select the relevant file and confirm sending it to Dext

- The item will then appear in the Costs Inbox
