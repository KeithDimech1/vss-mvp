This error is due to the user profile that has been used to log into Sage 50 does not have sufficient permission to run the report. The access rights for this user need to be updated with the correct permission level by the Sage 50 administrator.

 

For instructions on how to update access rights [click here](https://ask.sage.co.uk/scripts/ask.cfg/php.exe/enduser/std_adp.php?p_faqid=14858)
