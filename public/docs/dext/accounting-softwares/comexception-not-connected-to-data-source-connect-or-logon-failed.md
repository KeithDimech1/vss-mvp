**If you&#x27;re using the Sage 50 integration and the above error message appears, it&#x27;s due to installing multiple instances of the same connector for one specific company. **

 

Follow these steps to fix the issue:

 

- Open the windows system tray (bottom right-hand corner) and identify the number of connectors that have been installed.

- Right-click each connector logo to open up the connector and see which company it is associated with.

- Identify any duplicate connectors and uninstall them.

- We suggest restarting the machine before re-publishing any items.
