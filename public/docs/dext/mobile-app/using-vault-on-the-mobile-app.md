**Access Vault and manage your documents directly from the mobile app.**

**Important**: To access Vault in the mobile app be sure you update your mobile app to the latest version.

See how to use Vault via the web app [here](https://help.dext.com/en/articles/339544-using-vault).

 

# How to access Vault

To open Vault in the mobile app:

- Tap **More**.

- Select **Vault**.

In the Vault space, you&#x27;ll find three tabs:

- **Folders** – View and organise documents into folders. New folders can be created when uploading documents.

- **Files** – See all uploaded documents, regardless of folder.

- **Review** – View documents that need attention. This includes:

Items with due dates within the next two weeks or that expired within the past week.

- Any items you’ve flagged. 

 

# Adding Documents to Vault 

To upload documents:

- Tap the **up arrow** next to the camera button.

- Select **Add to Vault**.

- Choose the files you&#x27;d like to upload and tap **Upload**.

**Note**: You can upload up to **10 documents** at once and the maximum file size is **100MB**.

- Select a folder to upload the documents into, or tap the **+** in the top-right corner to create a new folder.

- Tap **Upload** again to confirm. 

Once uploaded, your documents will appear in both the **Files** tab and within the selected **Folder**.

 

 

## Managing documents in Vault

To edit or manage a document:

- Tap the document to open it.

You can add details such as **due date** and **summary**.**​ 

To access more options, tap the three dots** in the top-right corner. From here, you can:

- Flag the item

- Download it

- Copy it to the **Cost** or **Sales** inbox

- Delete the item 

 

 

# Using Tags

You can assign tags to documents to help with organisation.

To do this:

- Tap **Tags** in the **File Details** section.

- Tap the **+** in the top-right corner to create a new tag, or select from existing tags.

- Once selected (you’ll see a checkmark next to each), tap the **back arrow** in the left hand corner, then tap **Apply** to confirm.

**Note**: To add instructions to a tag, you&#x27;ll need to use the web app. Take a look at [this article](https://help.dext.com/en/s/article/using-vault#manage-tags) for more details.

  

If a document has tags, they&#x27;ll be visible in both the **Files** and **Folders** tabs.

  

 

## Changing the view in Vault

You can switch between **list view** and **grid view** for better visibility of your files. 

 

To change the view:

 

 1. Tap the **view icon** in the top-right corner.

   

 

## Moving items to the Vault

If a document was added to the **Cost** or **Sales** inbox instead of Vault, you can move it by:

- Opening the document.

- Tapping the **three dots** in the top-right corner.

- Selecting **Move to Vault**.

- Choosing a folder, or tapping the **+** to create a new one.

- *(Optional)* Checking the box to **keep a copy** in the original inbox.

- Tap **Confirm**.
