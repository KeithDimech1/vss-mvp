# You can securely log into the mobile app using your fingerprint or FaceID.

 

To set up Biometric Authentication, you’ll need to:

 

- Log into the Mobile App

- Click **Settings **in the bottom right corner.

- Toggle the **Biometrics** option to switch it **on**.

- Confirm the set up, by using your fingerprint or FaceID.

**Note**: If you&#x27;re unable to login using your fingerprint or FaceID, you can still log into Dext using your email address and password.
