1. Overview
EarthBank (
https://ausgeochem.auscope.org.au
)
 is Australia's national cloud-based public repository for geochemistry, geochronology,
 isotopes, and thermochronology data. Co-developed by Lithodat Pty Ltd and AuScope
 Geochemistry Network, EarthBank represents a $21 million investment in national research
 infrastructure funded by the Australian Research Council (ARC) and administered through
 AuScope Ltd.
The platform consolidates analytical data from over $100 million in laboratory
 instrumentation across 10 Australian universities, making Australia's geoscience
 research outputs Findable, Accessible, Interoperable, and Reusable (FAIR). This
 directly mirrors GDAC-SA's mandate to centralize and standardize geoscience data
 at a national scale.
2. Technical Architecture
2.1 Cloud Infrastructure
Hosting:
Amazon Web Services (AWS) - ensuring global availability and enterprise-grade security
Database:
PostgreSQL with PostGIS extensions for advanced spatial queries
API Layer:
RESTful API enabling programmatic data access and third-party integrations
Frontend:
React-based web application with interactive mapping and visualization tools
2.2 Data Integration Pipeline
EarthBank implements a sophisticated AI-assisted data pipeline that:
Ingests raw analytical outputs from 10+ laboratory systems
Validates data against CGI/OGC geochemical standards
Applies machine learning for automated mineral classification and quality control
Geocodes samples using Australian national stratigraphic databases
Generates persistent identifiers (Litho-IDs) for data citation
2.3 Analytical Capabilities
The platform supports advanced geoscience workflows including:
Geochemical Analysis:
Multi-element whole-rock and mineral chemistry
Geochronology:
U-Pb, Ar-Ar, Lu-Hf, Sm-Nd isotopic dating
Thermochronology:
(U-Th)/He and fission-track low-temperature dating
Spatial Analytics:
Geospatial mapping, regional geochemical trends, proximity searches
Statistical Tools:
Multi-variate analysis, machine learning classification
