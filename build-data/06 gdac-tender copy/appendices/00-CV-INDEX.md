## How to Use

### Opening in Microsoft Word

1. Right-click on the HTML file
2. Select "Open with" → "Microsoft Word"
3. Word will import the HTML and display it with proper formatting
4. Save as .docx if needed

### Converting to PDF

**Option 1: Using Microsoft Word**
1. Open the HTML file in Word (see above)
2. File → Save As → PDF

**Option 2: Using Print to PDF (Mac)**
1. Open the HTML file in Safari or Chrome
2. File → Print
3. Select "Save as PDF" from the print dialog

**Option 3: Using Command Line (if wkhtmltopdf installed)**
```bash
wkhtmltopdf CV-01-Fabian-Kohlmann.html CV-01-Fabian-Kohlmann.pdf
```
