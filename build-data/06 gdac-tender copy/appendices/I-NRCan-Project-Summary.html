About the CATCH Database

Authors: J.W. Powell (GSC), D.A. Kellett (GSC), F. Kohlmann (Lithodat), and M. McMillan (Lithodat/University of Melbourne)

What is Low-Temperature Thermochronology? Low-temperature thermochronometers, such as fission track and (U-Th)/He systems, are radiometric dating methods sensitive to low (<~300°C) temperature regimes characteristic of relatively shallow depths in Earth's crust. LTT provides temporal constraints on a range of important upper crustal geological processes, including:

  • Tectonic exhumation – Unroofing and uplift of mountain belts
  • Climatic exhumation – Erosion driven by glacial and fluvial processes
  • Brittle deformation – Faulting and fracturing events
  • Sedimentary burial – Basin subsidence and thermal maturation
  • Hydrothermal fluid circulation – Mineral deposit formation
  • Crustal heat flow changes – Geothermal evolution over time

The unique ability of LTT to unravel the thermal history of rocks renders these methods invaluable for assessing the geodynamic and surficial processes that have impacted Canada's bedrock throughout geologic time.

1. Executive Summary

1.1 What is the CATCH Database?

The Canadian ThermoCHronology (CATCH) database is a comprehensive national repository for low-temperature thermochronology data from across Canada. The database integrates 996 fission track datapoints and 762 (U-Th)/He datapoints from 1,427 unique samples, further divided into:

  • 16,277 single grain fission track measurements
  • 27,848 fission track length measurements
  • 3,230 aliquots of (U-Th)/He data

The project represents a multi-year collaboration between Lithodat Pty Ltd and Canada's Geological Survey (Natural Resources Canada), involving extensive data mining, legacy data digitization, quality control, and standardization across 91 different data sources spanning five decades (1970-2021).

2. Data Extraction and Curation Methodology

2.1 Multi-Source Data Integration

Data extraction involved extensive data mining of all LTT data and associated metadata for northern Canada from 91 different data sources. The project required specialized approaches for different data formats:

Data Format Extraction Method Quality Control
Modern Digital Publications Direct extraction from digital tables (copy/paste to Excel) Row-by-row validation against source
Analogue Paper Reports Manual data entry from physical documents Double-entry verification
Non-Vectorized PDFs OCR extraction with manual correction Character-by-character validation
Published Figures/Histograms Digital extraction using image analysis tools Statistical comparison to published summaries
Maps Without Coordinates Georeferencing using GIS software Cross-validation with regional geology

2.2 Comprehensive Metadata Capture

At the sample level, CATCH captures extensive metadata to enable reuse and reinterpretation of historical data:

  • Sample Metadata: Name, coordinates, location name/description, location type, sampling method, rock type, stratigraphic unit, elevation
  • Analytical Metadata: Laboratory, analyst, analytical method, measurement date, equipment used
  • Kinetic Parameters: Dpar, chlorine content, radiation damage, etching conditions—essential for thermal history modeling
  • Provenance Metadata: Funding sources, chief investigator, publication reference, digital object identifier (DOI)
  • Quality Metrics: Number of grains analyzed, track counts, uncertainties, quality flags

2.3 Georeferencing and Spatial Integration

For publications where sample coordinates were not provided, locations were determined via systematic georeferencing of geologic maps. This process involved:

  • Digital extraction of geologic maps from publications
  • Georeferencing maps using GIS software (QGIS, ArcGIS)
  • Digitizing sample locations from georeferenced maps
  • Cross-validation with regional geological frameworks
  • Assignment of confidence levels to georeferenced coordinates

3. Database Architecture and Data Model

3.1 Thermochronology-Specific Data Structure

The CATCH database employs a purpose-built data structure tailored to low-temperature thermochronology requirements. The data model accounts for different thermochronometers, various analytical generations, and corresponding metadata:

Fission Track Data Structure

  • FT Datapoints: Bulk fission track data for all samples (central ages, pooled ages, summary statistics)
  • FT Count Data: Fission track counting statistics (spontaneous tracks, induced tracks, uranium concentrations)
  • FT Single Grain: Individual grain ages and kinetic parameters
  • FT Length Data: Individual fission track length measurements
  • FT Binned Length Data: Length distributions digitized from published histograms

(U-Th)/He Data Structure

  • He Datapoints: Summary data for all samples (mean ages, weighted mean ages)
  • He Whole Grain: Detailed aliquot data (single grain or multi-grain analyses)
  • He Kinetic Parameters: Effective uranium (eU), grain dimensions, alpha ejection corrections

3.2 Modern Data Reporting Standards

The CATCH database structure adheres to international thermochronology community guidelines for data reporting:

  • Fission Track: Aligned with Kohn et al. (2024) community standards for fission track data reporting
  • (U-Th)/He: Follows Flowers et al. (2023a, b) guidelines for (U-Th)/He chronology data and uncertainty reporting
  • Extensibility: Database structure designed to accommodate future analytical methods and evolving reporting standards

3.3 Data Reusability Framework

A critical design principle of CATCH is enabling functional reuse of historical data through modern analytical lenses. This is essential because:

  • Evolving Kinetic Models: Laboratory-defined models for thermal diffusion and annealing are routinely updated and improved
  • New Modeling Software: Advanced codes for numerical thermal history modeling are continually published
  • Big Data Approaches: Modern methods derive regional geologic histories from large LTT datasets requiring comprehensive metadata

By capturing comprehensive analytical metadata, CATCH ensures that a single apatite fission track age from a 1970s publication (with minimal reported metadata) can be reanalyzed using modern kinetic models alongside contemporary samples with >3000 unique data entries per sample.

4. Data Coverage and Scientific Impact

4.1 Geographic Coverage

The northern Canada CATCH compilation provides comprehensive coverage of key tectonic and geological provinces:

  • Northern Canadian Cordillera: Extensive data documenting Mesozoic to Eocene mountain building and exhumation
  • Arctic Islands: Data constraining burial and exhumation in Franklinian Basin and Sverdrup Basin
  • Canadian Shield: Critical data revealing dynamic cratonic response to far-field stresses through deep time
  • Eurekan Orogeny: Thermochronology documenting Eocene orogenesis along Arctic margin

The CATCH database infrastructure enables advanced research applications that were previously impossible without centralized data access:

  • Big Data Thermochronology: Statistical analysis of continental-scale exhumation patterns (Boone et al. 2023, Scientific Reports)
  • Machine Learning Applications: Training datasets for ML-based thermal history inversion algorithms
  • Regional Synthesis: Identification of first-order tectonic events affecting Canada's bedrock evolution
  • Gap Analysis: Systematic identification of under-sampled geological provinces requiring new data acquisition
  • Legacy Data Reinterpretation: Re-analysis of historical data using modern kinetic models and thermal history modeling codes
