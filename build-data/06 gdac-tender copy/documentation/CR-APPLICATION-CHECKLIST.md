## Pre-Application: Documents to Prepare NOW (While Waiting for MISA)

### 1. Parent Company Documents

| Document | Status | Notes |
|----------|--------|-------|
| [ ] Lithodat Certificate of Incorporation | | From home country |
| [ ] Lithodat Commercial Registration (home country) | | Must be authenticated by Saudi Embassy |
| [ ] Board Resolution authorizing Saudi expansion | | Must specify: establishment of Saudi subsidiary, authorized capital, appointment of GM |
| [ ] Financial Statements (latest year) | | Audited, authenticated by Saudi Embassy |
| [ ] Arabic translations of all above | | Certified translation required |

### 2. Articles of Association (Must Draft)

| Item | Status | Notes |
|------|--------|-------|
| [ ] Draft Articles of Association in Arabic | | Defines company structure, ownership, management |
| [ ] Define shareholding structure | | Who owns what % |
| [ ] Define management structure | | GM appointment, board if applicable |
| [ ] Define capital amount | | Minimum SAR 100,000 for most activities |
| [ ] Have AoA notarized | | After MISA approval |

**Articles of Association Must Include:**
- Company name (Arabic + English)
- Company purpose/activities
- Registered address
- Capital amount and structure
- Shareholder names, nationalities, ownership %
- Management structure
- Fiscal year
- Profit distribution method
- Dispute resolution

### 3. General Manager Documentation

| Document | Status | Notes |
|----------|--------|-------|
| [ ] GM passport copy | | Valid for 6+ months |
| [ ] GM CV/resume | | |
| [ ] GM appointment letter | | From Board Resolution |
| [ ] GM power of attorney | | If GM will handle registration |

### 4. Saudi Embassy Authentication

**CRITICAL:** The following documents must be authenticated by the Saudi Embassy in your country BEFORE you can use them:

| Document | Embassy Authentication | Notes |
|----------|----------------------|-------|
| [ ] Parent company commercial registration | [ ] Authenticated | Takes 1-2 weeks |
| [ ] Financial statements | [ ] Authenticated | |
| [ ] Board resolution | [ ] Authenticated | |

**Process:**
1. Get documents notarized in home country
2. Apostille (if Hague Convention country) OR legalize through foreign ministry
3. Submit to Saudi Embassy for authentication
4. Embassy stamps/certifies documents

**Portal:** mc.gov.sa → E-Services → Name Reservation

| Task | Status |

**Name Rules:**
- Can be Arabic, English, or hybrid (as of 2024)
- Must be unique
- Cannot be misleading

## Common Mistakes to Avoid

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| Documents not embassy-authenticated | Application rejected | Start authentication NOW |
| Name not available | Delays | Prepare 3 name options |
| Incomplete AoA | Rejection | Use lawyer or template |
| Wrong business activity codes | Limits future operations | Select all applicable codes |
| Capital below minimum | Rejection | Ensure SAR 100,000 minimum |
| Missing translations | Application rejected | Use certified translators |
