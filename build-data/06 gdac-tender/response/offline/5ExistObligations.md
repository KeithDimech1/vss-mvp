## 5. How the GDAC Project Fits into Current Workload

A critical efficiency factor is that **all Lithodat platforms, including EarthBank, the Thermochronology Platform and the Isotope Platform, are built on Lithodat’s core software framework: LithoSurfer.**

LithoSurfer provides:

- A shared codebase  
- A unified data model architecture  
- Pre-built ingestion and QA/QC pipelines  
- A configurable analytics engine  
- Rapid deployment tooling  

### **What this means for GDAC-SA**
- Deploying GDAC-SA would **not require creating a new platform from scratch**  
- Core modules (data ingestion, standardisation, QA/QC, spatial analytics) already exist  
- Only Saudi Arabia–specific data models and connectors need to be added  
- Development time and risk are significantly reduced  
- Lithodat can quickly adapt the platform as GDAC evolves over its four phases  

**Conclusion:**  
GDAC-SA fits seamlessly into Lithodat’s workload due to the reusability and modularity of the LithoSurfer platform.
