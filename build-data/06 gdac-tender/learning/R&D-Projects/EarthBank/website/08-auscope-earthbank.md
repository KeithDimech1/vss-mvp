# AuScope EarthBank Platform
**URL:** https://www.auscope.org.au/earthbank
**Captured:** 2025-11-30

---

## Core Purpose

EarthBank is a geochemistry data platform enabling researchers to visualize, analyze, and extract georeferenced data from laboratories worldwide. It represents the initial phase of the AuScope Geochemistry Network's mission to establish "a coherent network of geochemical laboratories" contributing to FAIR (Findable, Accessible, Interoperable, Reusable) data repositories.

---

## Key Features

### Data Visualization & Access
- Interactive mapping for viewing areas of interest
- Multi-method data synthesis capabilities
- Support for extraction in multiple formats compatible with various software systems

### Data Types Supported

| Data Type | Description |
|-----------|-------------|
| **LA-ICP-MS U-Pb geochronology** | Laser ablation dating |
| **SIMS U-Pb geochronology** | Secondary ion mass spectrometry dating |
| **Major, minor, and trace element geochemistry** | Bulk rock composition |
| **K-Ar and Ar-Ar geochronology** | Potassium-argon dating |
| **Fission track thermochronology** | Thermal history from fission tracks |
| **(U-Th-Sm)/He thermochronology** | Low-temperature thermal history |
| **Thermal history simulations** | Modeling temperature evolution |
| **Hf-isotope geochemistry** | Hafnium isotope analysis |

### Analysis Tools

The platform leverages Lithodat technology, providing built-in functions including:
- Cumulative age histograms
- Age versus elevation plots
- Step-heating diagrams for rapid comparative analysis
