# AuScope Virtual Research Environment (AVRE)
**URL:** https://www.auscope.org.au/avre
**Captured:** 2025-11-30

---

## Core Purpose

The AVRE serves as "Australia's home of geoscience data and tools" enabling scientists to advance understanding of continental geology. It functions as a "rich ecosystem of Findable, Accessible, Interoperable and Reusable (FAIR) data" contributed by diverse Australian research organizations and international partners.

---

## Key Data & Tool Components

### Primary Toolkit

| Tool | Description |
|------|-------------|
| **Solid Earth Applications** | Simulation, Analysis & Modelling (SAM) program tools |
| **AuScope Portal** | Web interface for searching and accessing geoscience data |
| **Geochemistry Applications** | Tools from AuScope Geochemistry Network |
| **Seismic Data Tools** | AuScope-sponsored seismic applications |
| **3D Geoscience Models** | Visualization application for geological models |
| **Geophysics Applications** | Integrated resources from AuScope, NCI, and the geophysics community |
| **AuScope Inversion Laboratory (iEarth)** | Collaborative tool for scientists across academia, government, and industry |
| **Virtual Geophysics Laboratory (VGL)** | Portal providing eResearch tools and cloud computing access |
| **Model Atlas of the Earth (M@TE)** | Open-source computational models focusing on tectonics, hydrogeology, and surface processes |

---

## Data Types Supported

- Geochemical data
- Geophysical data
- Passive seismic data
- Magnetotelluric (MT) data
- Historical datasets

The system processes data "from samples, to data, to analysis, to research publication" in real-time.

## Current Development Projects

### AVRE Build Program
Collaborative projects with universities exploring new applications and technologies.

### AusPass Portal
Dedicated service for passive seismic and magnetotelluric data acquisition and distribution.

### Modernising Earth Science Data for HPC
NCRIS-supported initiative transforming geophysical datasets for high-performance computing compatibility.
