# National Virtual Core Library (NVCL)
**URL:** https://www.auscope.org.au/nvcl
**Captured:** 2025-11-30

---

## Core Mission

The NVCL is "the world's largest online drill core mineralogical database, with over 1.6 million meters of drill core data freely accessible" to researchers globally. It provides both data infrastructure and expertise in drill core analysis.

---

## Technology Infrastructure

### HyLogger Systems

The NVCL backbone comprises two primary instruments:
- **CSIRO-developed HyLogger-3** hyperspectral core-scanning system
- **Corescans' newer HyLogger-4** system

These systems generate:
- Continuous reflectance spectroscopy data
- Automated mineralogical interpretation
- High-resolution core photography

### Geographic Distribution

Six State and Territory geological surveys operate HyLogger facilities across Australia:
- New South Wales (NSW)
- Northern Territory (NT)
- Queensland (QLD)
- South Australia (SA)
- Tasmania (TAS)
- Western Australia (WA)
- Victoria (VIC)

This ensures nationwide representation of geological data collection.

| Tool | Description |
|------|-------------|

| **AuScope Discovery Portal** | Online database with Data Analytics Layer allowing searches across 5,900+ drill core datasets |
| **NVCL Explorer** | Web application for data visualization |
| **NVCL-kit** | Python package for data access |

## Current Research Focus

1. **Data Quality & Interpretation:** Enhancing mineral spectral reference libraries for improved automated identification
2. **Infrastructure Expansion:** Utilizing portable tools to access regionally stored cores
3. **FAIR Data Principles:** Developing interoperable, reusable datasets with improved visualization tools
4. **Training & Outreach:** Regular workshops and annual technical meetings
