# Simulation, Analysis & Modelling (SAM) Program
**URL:** https://www.auscope.org.au/sam
**Captured:** 2025-11-30

---

## Overview

SAM provides "open-source software that helps researchers and industry model and visualise the Earth's dynamic systems" spanning from mantle processes to surface environments. The program supports research in geodynamics, resource exploration, energy, mining, and natural hazard studies.

---

## Core Research Tools

### Underworld

| Feature | Description |
|---------|-------------|
| **Type** | High-performance, open-source geodynamic simulation code |
| **Methodology** | Particle-in-cell finite element |
| **Interface** | Python-based, optimized for parallel computing |
| **Applications** | Plate movement, subduction, basin evolution, crustal deformation |
| **Availability** | Docker Hub; includes user manual and source code repository |

### GPlates

| Feature | Description |
|---------|-------------|
| **Type** | Interactive desktop application for plate tectonic exploration |
| **Capabilities** | Plate reconstruction, GIS functionality, raster visualization |
| **Applications** | Continental/ocean basin movements, paleogeography, sediment transport |
| **Platforms** | Windows, Linux, macOS |

### GAdopt

| Feature | Description |
|---------|-------------|
| **Type** | Framework for Glacial Isostatic Adjustment and Earth deformation modeling |
| **Capabilities** | Integrates solid-Earth physics, ice-mass changes, sea-level variations |
| **Applications** | Planetary response to surface loading over geological timescales |

### M@TE (Model Atlas of the Earth)

| Feature | Description |
|---------|-------------|
| **Type** | Modeling environment for coupled thermal and mechanical mantle evolution |
| **Capabilities** | Mantle convection, heat transport, surface-to-deep-Earth linkages |
| **Integration** | Works with other geodynamic models |
