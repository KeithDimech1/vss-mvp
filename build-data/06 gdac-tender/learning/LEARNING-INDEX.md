## Platform Summaries

### 1. EarthBank (AuScope Geochemistry Network)

**Status:** Production
**Users:** 1,300+
**Samples:** 350,000+
**Funding:** NCRIS ($19M program)

**Key Capabilities:**
- FAIR-compliant geochemistry data platform
- Multi-data type support (U/Pb, fission track, (U-Th)/He, geochemistry)
- LithoPlates paleogeographic reconstruction (11 plate models, to 1.8 Ga)
- DOI/IGSN minting
- REST API for machine-to-machine interoperability

**Key Evidence:**
- Peer-reviewed publication in Chemical Geology (2025)
- EGU General Assembly 2025 abstract
- Workshop manuals for international conferences
- Saudi Arabia national platform proposal

**Status:** Active R&D (July 2024 - December 2028)
**Budget:** $300,000
**Partners:** CSIRO, ANSTO, GA, NMI

**Key Capabilities:**
- Unified schema for environmental isotope data
- Automated adapter ingestion from institutional sources
- Semi-automated import wizard for legacy data
- FAIR-compliant metadata enrichment
- Cross-agency data harmonisation

**R&D Experiments:**
1. Adapter Validation (6 institutional sources)
2. Import Wizard Benchmarking (93-96% accuracy)

### 3. LithoSpace (Extraterrestrial Geochemistry Platform)

**Status:** Active R&D
**Partners:** RMIT University, University of Melbourne
**Achievement:** First spatial platform for lunar/Mars geochemistry

**Key Capabilities:**
- Cross-mission data integration (25+ missions, 1967-2025)
- Unified schema for planetary geochemistry
- Lunar missions: Apollo 11-17, Luna 16/20/24, Chang'e
- Mars missions: Viking, Pathfinder, Spirit, Opportunity, Curiosity, Perseverance

**R&D Experiments:**
1. Lunar Ingestion Expansion (Apollo + Luna missions)
2. Mars Comparison Dashboard (multi-rover visualization)
3. Schema Justification (literature review confirming novel approach)
