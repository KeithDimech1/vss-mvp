1. Executive Summary

1.1 What is EarthBank?

EarthBank is an Australian national cloud-based public data repository for geochemistry, geochronology, isotopes, thermochronology, and geological sample metadata. Lithodat designed, built, and operates the entire platform under contract to AuScope Geochemistry Network (AGN), funded through Australia's National Collaborative Research Infrastructure Strategy (NCRIS).

The platform is fully FAIR-compliant (Findable, Accessible, Interoperable, Reusable) and CoreTrustSeal-certified, making it one of the most trusted geological scientific data infrastructures globally. EarthBank serves as Australia's centralized repository for analytical geoscience data, unifying datasets from federal and state geological surveys, universities, and research institutions.

AuScope NCRIS Funding Context

EarthBank is part of AuScope, Australia's national geoscience research infrastructure organization established in 2006. AuScope has received over $100 million in cumulative NCRIS funding since inception, including:

  • $42.8 million initial NCRIS allocation (2006) for integrated national geoscience infrastructure
  • $45 million NCRIS RIIP funding (2023) for Earth, coastal, Antarctic monitoring, drilling, data, and modelling
  • $19 million specifically allocated for EarthBank expansion, including 10 EarthBank fellows

This substantial government investment demonstrates Australia's recognition of national geoscience data infrastructure as critical research infrastructure—exactly the paradigm GDAC-SA seeks to implement for Saudi Arabia.

2. AI and Machine Learning Capabilities

2.1 AI-Ready Data Architecture

EarthBank was designed from inception to support advanced analytics and machine learning applications. The platform's data architecture includes:

  • Standardized Data Schemas: Custom SKOS-format relational database architecture ensures consistent, machine-readable data structures optimized for ML algorithms
  • REST API Access: Full programmatic access to all datasets enables integration with external ML workflows, Python-based analytics tools, and automated data pipelines
  • Spatial-Temporal Analytics: 4D data structures (x, y, z, time) with paleogeographic reconstruction capabilities support temporal machine learning models for mineral prospectivity
  • Quality Metadata: Automated QA/QC pipelines and comprehensive procedural metadata enable ML models to assess data quality and uncertainty
  • Cloud-Native Infrastructure: 100% AWS-hosted architecture provides scalable compute resources for on-demand ML processing

5.2 Platform Features

  • Map View: Interactive spatial visualization with multiple basemaps (satellite, geology, topography)
  • 3D View: Globe view and terrain visualization with analytical data overlay
  • Data Packages: Project-based data organization with granular sharing controls and permissions
  • Analytical Layers: Technique-specific data filtering and visualization dashboards
  • LithoPlates: Paleogeographic reconstruction tool (11 different plate tectonic models, time steps to 1.8 Ga)

  • Interpolation: On-the-fly Inverse Distance Weighting (IDW) interpolation for creating continuous geochemical maps
  • Swath Profiles: Elevation and sample profile analysis along user-defined transects

  • IGSN Minting: International Geo Sample Number registration for sample provenance
  • REST API: Full programmatic access for machine-to-machine interoperability
