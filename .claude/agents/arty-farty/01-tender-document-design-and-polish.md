## What This Lesson Covers

This lesson documents a systematic approach for taking content-corrected tender and proposal documents and applying professional visual design to create submission-ready materials.

**Two-stage workflow:**
1. **Stage 1 (Jon Monk):** Content quality - Fix critical errors, improve copy, ensure consistency ✅
2. **Stage 2 (Arty Farty):** Visual design - Layout, typography, professional polish ← THIS LESSON

**Prerequisites:**
- Jon Monk has completed content review
- All critical and important issues are fixed
- Content is accurate, consistent, and complete

## Design Methodology

### Step 1: Receive Handoff from Jon Monk (5-10 minutes)

**Goal:** Understand content and design requirements before starting visual work

**Review the design brief:**
```markdown
## Design Brief: [Project Name]

**Document Type:** Tender response / Proposal / Report
**Page Count:** X pages
**Deadline:** [Date]

**Design Requirements:**
- Professional, corporate style
- Client industry: [e.g., Government, Mining, Geoscience]
- Target audience: [e.g., Technical evaluators, Executives]
- Branding: [Company colors, logo usage guidelines]

**Key Sections Needing Visual Enhancement:**
1. Executive Summary (most important)
2. Project examples (add visual interest)
3. Financial tables (ensure easy to scan)
4. Organization chart (create clean visual hierarchy)

**Output Format:**
- [PDF for digital submission]
- [Word + PDF for print and digital]
```

**Ask Jon Monk if anything is unclear:**
- Are there sections where content is still being finalized?
- Any specific client preferences for visual style?
- Deadline flexibility if design takes longer than expected?

### Step 2: Establish Visual System (20-30 minutes)

**Goal:** Define design rules that will be applied consistently across all documents

#### Typography Hierarchy

**Establish 5 levels:**

1. **Document Title** (largest, bold)
   - Example: "GDAC-SA PRE-QUALIFICATION RESPONSE"
   - Font size: 24-28pt
   - Color: Brand primary (e.g., dark blue)
   - Spacing: Large top/bottom margins

2. **Section Headers** (H1)
   - Example: "EXECUTIVE SUMMARY", "TECHNICAL CAPABILITIES"
   - Font size: 18-20pt
   - Color: Brand primary
   - Uppercase, bold
   - Page break before (start on new page)

3. **Subsection Headers** (H2)
   - Example: "4.1 Previous Work Experience"
   - Font size: 14-16pt
   - Color: Brand primary or dark gray
   - Bold, mixed case
   - Space above/below

4. **Sub-subsection Headers** (H3)
   - Example: "Key Performance Outcomes"
   - Font size: 12-14pt
   - Bold, mixed case
   - Subtle color or all-caps for distinction

5. **Body Text**
   - Font size: 10-11pt
   - Color: Dark gray (#333333 or similar)
   - Line spacing: 1.15-1.3
   - Left-aligned (not justified - easier to read)

#### Color Palette

**Define 3-4 colors:**

1. **Brand Primary** (for headers, accents)
   - Example: Navy blue (#003366)
   - Use: Major headers, table headers, key callouts

2. **Brand Secondary** (for highlights, charts)
   - Example: Gold/orange (#D4A017)
   - Use: Data visualization, icons, pull quotes

3. **Neutral Dark** (for body text)
   - Example: Charcoal (#333333)
   - Use: All body text, captions

4. **Neutral Light** (for backgrounds, borders)
   - Example: Light gray (#F5F5F5)
   - Use: Table backgrounds (zebra striping), section backgrounds

**Test color combinations for accessibility:**
- Ensure sufficient contrast (WCAG AA minimum: 4.5:1 for body text)
- Avoid pure black on pure white (harsh - use dark gray on off-white)

#### Layout Grid

**Establish page margins and structure:**

- **Page margins:** 2.5cm (1 inch) all sides
  - Or: 3cm top/bottom, 2.5cm left/right for more vertical space
- **Header/footer:** 1.5cm from edge
- **Column width:** Single column (easier to read for text-heavy documents)
- **Table width:** Full page width or centered with padding

### Step 3: Design Key Pages (60-90 minutes)

**Goal:** Create 3-4 template pages that establish the visual system

#### Template 1: Cover Page

**Elements:**
- Company logo (top left or centered)
- Document title (large, centered, bold)
- Subtitle / Project description
- Client logo or name (if appropriate)
- Submission date
- Company contact information (footer)
- Professional image (optional - geoscience related for this project)

**Visual hierarchy:**
```
┌─────────────────────────────┐
│ [Logo]                      │
│                             │
│                             │
│   DOCUMENT TITLE            │
│   Subtitle / Description    │
│                             │
│   Client Name               │
│   Submission Date           │
│                             │
│                             │
│ Company Info (footer)       │
└─────────────────────────────┘
```

#### Template 2: Table of Contents

**Elements:**
- Clear "Table of Contents" header
- Hierarchical list with indentation
- Page numbers right-aligned
- Dotted leaders connecting titles to page numbers
- Optional: Section dividers

**Visual hierarchy:**
- Major sections: Bold, larger font
- Subsections: Regular weight, indented
- Sub-subsections: Smaller font, further indented

#### Template 3: Content Page with Text

**Elements:**
- Page header: Document name (small, top center or top left)
- Page number (bottom center or top right)
- Section header (large, brand color)
- Body text (readable size, proper spacing)
- Pull quotes or callouts (if applicable)

**Layout example:**
```
┌─────────────────────────────┐
│ Document Name         Page 5│
├─────────────────────────────┤
│                             │
│ SECTION HEADER              │
│                             │
│ Body text paragraph 1...    │
│                             │
│ Body text paragraph 2...    │
│                             │
│ ┌─────────────────────┐     │
│ │ Pull Quote or       │     │
│ │ Key Statistic       │     │
│ └─────────────────────┘     │
│                             │
│ Body text continues...      │
└─────────────────────────────┘
```

#### Template 4: Content Page with Tables

**Elements:**
- Same header/page number as text pages
- Section header
- Table with:
  - Header row (brand color background, white text)
  - Zebra striping (alternating row colors for readability)
  - Column alignment (numbers right-aligned, text left-aligned)
  - Borders (subtle, not heavy)

**Table design best practices:**
- **Header row:** Bold, brand primary background, white text
- **Row striping:** Every other row light gray background (#F9F9F9)
- **Borders:** Light gray (#DDDDDD), 0.5pt width
- **Cell padding:** 8-10pt top/bottom, 10-12pt left/right
- **Font size:** 9-10pt (can be smaller than body text for data tables)

### Step 4: Apply Design to All Pages (90-120 minutes)

**Goal:** Systematically apply visual system to entire document

**Work through document in order:**

#### 4.1 Executive Summary
**Priority:** HIGHEST - This is what evaluators read first

- **Lead with visual impact:** Consider colored background box or border
- **Break into digestible chunks:** Use subheadings
- **Highlight key statistics:** Use callout boxes or bold numbers
- **Add visual elements:** Icons, small charts, or diagrams if appropriate

**Example enhancement:**
```
┌─────────────────────────────────────┐
│ EXECUTIVE SUMMARY                   │
├─────────────────────────────────────┤
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ [Icon] We have delivered 3      │ │
│ │ national government projects    │ │
│ │ totaling $3.7M AUD              │ │
│ └─────────────────────────────────┘ │
│                                     │
│ Paragraph text explaining value     │
│ proposition...                      │
└─────────────────────────────────────┘
```

#### 4.2 Company Information Sections
**Priority:** Medium

- **Tables:** Apply table design system consistently
- **Contact info:** Use icons for phone, email, website (optional)
- **Company structure:** Consider visual org chart instead of text list

#### 4.3 Technical Capabilities / Project Examples
**Priority:** High

- **Project summaries:** Use consistent format
  - Project name (bold)
  - Client (with logo if available)
  - Key metrics (in callout boxes or highlighted)
  - Brief description
  - Visual elements (screenshots of platforms, charts)

- **Add visual interest:**
  - Screenshots of EarthBank platform
  - Diagrams of data pipeline (already in content - ensure high quality)
  - Maps showing project locations
  - Before/after data quality comparisons

#### 4.4 Financial Tables
**Priority:** High

- **Apply zebra striping** for easy row tracking
- **Right-align numbers** for easy comparison
- **Bold totals row** to stand out
- **Currency labels** in header (AUD / SAR)
- **Consider visual elements:** Small bar charts inline for growth trends

#### 4.5 Appendices
**Priority:** Medium-Low

- **Maintain consistency** with main document
- **Clear appendix labels:** "Appendix E: Quality Management Policy"
- **Page numbering:** Continue from main document or use separate (E-1, E-2, etc.)
- **Formatting:** Can be simpler than main doc, but still professional

**Enhance existing diagram with:**

- Directional arrows showing flow
- Icons for each stage (optional)

#### Project Location Maps

**If showing project locations (Australia, Canada):**
- Simple map with markers
- Labels for project names

### Step 6: Consistency Check and Polish (30-45 minutes)

**Goal:** Ensure visual consistency across entire document

**Checklist:**

#### Typography Consistency
- [ ] All H1 headers use same font, size, color
- [ ] All H2 headers use same font, size, color
- [ ] Body text is consistent throughout
- [ ] No random bold/italic/underline usage
- [ ] Font sizes are harmonious (not too many different sizes)

#### Color Consistency
- [ ] Brand colors used consistently
- [ ] No random colors introduced
- [ ] Tables all use same color scheme
- [ ] Callout boxes use consistent styling

#### Spacing Consistency
- [ ] Margins are consistent on all pages
- [ ] Headers have consistent spacing above/below
- [ ] Paragraph spacing is uniform
- [ ] Table spacing is consistent

#### Page Structure
- [ ] Headers and footers appear on all pages (or where intended)
- [ ] Page numbers are sequential and correctly placed
- [ ] Major sections start on new pages (where appropriate)
- [ ] No orphans (single lines at top/bottom of page)
- [ ] No widows (last line of paragraph alone on new page)

#### Visual Elements
- [ ] All images are high resolution (not pixelated)
- [ ] Diagrams are clear and readable
- [ ] Tables fit properly on pages (no awkward breaks)
- [ ] Icons (if used) are consistent style

### Step 7: Final Quality Check (15-20 minutes)

**Goal:** Catch any remaining issues before delivery

**Print preview / PDF review:**
- View entire document as it will appear to client
- Check for formatting issues that weren't visible in editing view
- Verify all pages look professional

**Specific checks:**
- [ ] Cover page looks polished and professional
- [ ] Table of contents is accurate and formatted well
- [ ] Executive summary makes strong visual impact
- [ ] All tables are readable and well-formatted
- [ ] Visual hierarchy is clear throughout
- [ ] No formatting errors (weird spacing, broken elements)
- [ ] File size is reasonable (if images are included)

**Test on different devices (if digital submission):**
- [ ] Opens correctly on Windows and Mac
- [ ] PDF renders properly in different PDF viewers
- [ ] Printable if needed (colors look good in grayscale)

## Key Design Principles for Tenders

### DO:
✅ **Professional over flashy** - Tenders are formal documents
✅ **Consistency is king** - Visual system applied everywhere
✅ **Accessibility matters** - Readable fonts, sufficient contrast
✅ **White space is your friend** - Don't cram too much on a page
✅ **Tables need design love** - Most important visual element
✅ **Guide the eye** - Visual hierarchy shows what's important
✅ **Test before delivery** - View as PDF, check print preview

### DON'T:
❌ **Over-design** - Tender is not a marketing brochure
❌ **Use too many fonts** - 1-2 font families maximum
❌ **Use too many colors** - Stick to brand palette (3-4 colors)
❌ **Make it hard to read** - Small fonts, low contrast, walls of text
❌ **Ignore client context** - Conservative industries prefer understated design
❌ **Forget about printing** - Even digital submissions might be printed
❌ **Change content** - Design enhances, doesn't alter Jon Monk's approved copy

## Tools and Techniques

### Microsoft Word Design
**For tender documents, Word is often the primary tool**

**Styles:**
- Use Word Styles (not manual formatting)
- Create custom styles for H1, H2, H3, Body, Table
- Allows quick global updates

**Tables:**
- Use Table Design tab for consistent styling
- Create custom table style and save
- Use "Repeat Header Row" for tables spanning multiple pages

**Page Layout:**
- Set up margins and orientation correctly
- Use section breaks for different headers/footers
- Master pages for consistent page numbers

**Images and Diagrams:**
- Insert as "In line with text" for stability
- Or use "Tight" wrapping with anchors locked
- Compress images to reduce file size (but maintain quality)

### Adobe InDesign (Advanced)
**For more complex design needs**

**When to use InDesign over Word:**
- Very complex layouts with many visual elements
- Need precise control over typography
- Creating marketing-heavy proposal (not standard tender)
- Master pages needed for complex header/footer variations

**Export:**
- High-quality PDF/X-1a for print
- PDF/A for long-term archival

### Design Assets Creation

**Diagrams:**
- Lucidchart, draw.io (for flowcharts, org charts)
- PowerPoint (surprisingly good for simple diagrams)
- Adobe Illustrator (for complex vector graphics)

**Charts and Graphs:**
- Excel or Google Sheets (then paste as high-res image)
- Datawrapper (for web-quality charts)

**Icons:**
- Font Awesome (free, web)
- Noun Project (free and paid)
- Custom creation in Illustrator

## Common Tender Design Challenges

### Challenge 1: Long Tables Breaking Badly

**Problem:** Financial or data tables span multiple pages and break awkwardly

**Solutions:**
- Use "Repeat Header Row" in Word so table headers appear on each page
- Add "Continued..." footer to table on first page
- Consider splitting very wide tables into multiple narrow tables
- Rotate page to landscape for very wide tables

### Challenge 2: Content Doesn't Fit on Pages

**Problem:** Section ends mid-page, awkward spacing

**Solutions:**
- Adjust paragraph spacing (slightly reduce space before/after)
- Use page breaks to start new sections on fresh pages
- Slightly reduce margins (but maintain professionalism)
- Edit content (with Jon Monk's approval) to tighten wording

### Challenge 3: Images Are Low Quality

**Problem:** Screenshots or photos look pixelated

**Solutions:**
- Request higher resolution images from source
- Recreate diagrams using vector graphics tools
- For screenshots: Capture at 2x size, then resize down (improves clarity)
- Use SVG format for logos (scales perfectly)

### Challenge 4: Client Has Specific Template

**Problem:** Client provides mandatory template that's ugly

**Solutions:**
- Use their template structure (required)
- Apply subtle improvements: Better fonts (within template constraints), improved table styling, better spacing
- Add visual elements where template allows (icons, small graphics)
- Focus on content quality - make information easy to find
